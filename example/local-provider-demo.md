# Local provider demo

This job tracks its project/issue state as YAML + Markdown files under
`.orcai-local/` next to this YAML file, instead of GitHub Projects/Issues.
Useful for trying out a job's fan-out behaviour without touching GitHub, or
for tracking work in a repo that's shared/synced via git rather than the
GitHub API.
